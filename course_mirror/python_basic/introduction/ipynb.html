.ipynb fájltípus

A feladatok megoldásai .ipynb kiterjesztésűek. Ezek szöveges állományok, ezért javasolt a linken jobb-klikk -> Mentés másként opció használata. Figyeljetek oda, hogy a megfelelő .ipynb kiterjesztéssel mentsétek le a fájlokat.

Ez a Jupyter fejlesztő környezet (korábbi nevén IPYthon NoteBook) saját szöveges fájformátuma. Egy extra réteget épít a Python kódrészletek köré, és úgynevezett cellákban tárolja őket. A kód cellák mellett szöveget vagy ábrákat tartalmazó cellákat is tartalmazhat. Ráadásul alkalmas arra, hogy az egyes cellák kódjait helyben, külön-külön futtassuk és jelenítsük meg hozzájuk a kimenetet.

A Jupyter fájlokat ritkán használják éles fejlesztési projektekben, és az extra funkciók egy újabb komplexitási réteget adnak a megértéshez, ezért a képzés során nem ebben a formában dolgozunk. Az .ipynb formátum viszont kiválóan alkalmas eredmények prezentálására (pl.: adataelemzés mellé ábrák, paraméterezett lekérdezések). Emiatt remek eszköz az oktatásban is, mert egyben, jól átlátható módon lehet vele példakódokat bemutatni. Ezért a tantárgy során kiadott gyakorló feladatokat általában .ipynb formátumban tesszük majd közzé.

Szerencsére az általunk használt VS Code környezet is képes feldolgozni ezt a fájltípust és jól átlátható módon megjeleníteni a tartalmát. Sőt, az egyes kód blokkok mellett megjelennek a futtatáshoz szükséges gombok is. A tárgy szempontjából nincs ezekre szükség, a kódok könnyen átmásolhatók .py kiterjesztésű fájlokba és úgy futtathatók. De, ha valaki szeretné használni a beépített futtatási megoldást, akkor csak kattintson valamelyik futtatás gombra. Ezt követően a VS Code felül feldobja az “Install/Enable suggested extensions Python + Jupyter” opció. Erre kattintva és a telepítési lépéseket követve engedélyezhetők a Jupyter funkciók.

Ha több Python verzió van a gépen, vagy nem az alapértelmezett könyvtárba van telepítve, akkor az .ipynb megnyitását követően az első futtatáskor mindig megkérdezi majd a VS Code, hogy melyik Python telepítést akarjuk használni a futtatáshoz. Ilyenkor csak ki kell választani a megfelelő verziót a legördülő listából és újra működik a futtatás.
