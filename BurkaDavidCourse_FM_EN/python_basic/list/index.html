The list is the most general modifiable sequence type. Its elements can be changed, swapped, extended or even deleted. A list can be, for example, a list of names, a sequence of numbers, or even a collection of further lists.

Creating lists

A list can be created by simple assignment, listing the elements in square brackets separated by commas.

fruits = ["apple","banana","cherry","melon"]
print(fruits)

['apple', 'banana', 'cherry', 'melon']

An empty list can be created in two ways:

l1 = []
l2 = list()
print(type(l1))
print(type(l2))

<class 'list'> 
<class 'list'>

A list can consist of elements of any type, and the types can also be mixed.

fruits = ["apple",13, False, 3.14]

Accordingly, lists can also be nested inside one another. A 3x3 matrix – such as a small correlation matrix – can be represented as follows:

matrix = [[1,2,3],[4,5,6],[7,8,9]]
print(matrix)

[[1, 2, 3], [4, 5, 6], [7, 8, 9]]

Immutable operations

From the point of view of the immutable operations there is no essential difference between the sequence types, so the sections below work in exactly the same way for every other type as well (including strings).

Querying list elements

The individual elements of a list can be queried with the help of the index (ordinal number) they occupy in the order. As in most programming languages, lists in Python are indexed from zero. So the first element of a list can be queried in the following way.

fruits = ["apple","banana","cherry","melon"]
print(fruits[0])

apple

In this context the code fragment fruits[0] behaves like a variable containing the first element of the list. So all those operations can be carried out with it that are available for a variable of the given type. The result can, for example, be converted to upper case with the instruction fruits[0].upper().

A range can also be given when querying, but care has to be taken that Python treats ranges as open on the right, so the last element will not be included in the result.

fruits = ["apple","banana","cherry","melon"]
print(fruits[1:3])

['banana', 'cherry']

Either end of the queried range can be left empty. In this case we query the elements up to the end of the corresponding side.

fruits = ["apple","banana","cherry","melon"]
print(fruits[:3])

['apple', 'banana', 'cherry']

If we leave off both ends of the range and simply give a colon, then we query all the elements of the list. It is important to note that the values appearing in the queried ranges are in fact copies of the original values in memory. This means that if we query the elements of the list with the colon and write the result into a variable, then we get a copy of the list. This is illustrated by the example below, in which, on changing one element of the original list, the contents of the copy made earlier do not change.

fruits = ["apple","banana","cherry","melon"]
fruits2 = fruits[:]
fruits[0] = "pear"

print(fruits)
print(fruits2)

['pear', 'banana', 'cherry', 'melon']
['apple', 'banana', 'cherry', 'melon']

It is generally true of the indexing of arrays that if we give a negative number, it counts the elements from the end of the array. -1 refers to the last element, -2 to the second to last, and so on.

fruits = ["apple","banana","cherry","melon"]
print(fruits[-1])

melon

And with the help of the index function the position of an element in the list can be found out.

fruits = ["apple","banana","cherry","melon"]
print(fruits.index("banana"))

1

The numeric value returned only gives the place of the first occurrence of the element. So if several “banana” entries appeared in the list, the result would still be 1. If, however, the element does not appear in the list even once, we get an error message.

fruits = ["apple","banana","cherry","melon"]
print(fruits.index("pear"))

The number of elements of a list

The number of elements of a list can be read out with the len() function.

fruits = ["apple","banana","cherry","melon"]
print(len(fruits))

4

Joining lists together

The + operator, applied to lists, is to be understood as joining them together.

fruits = ["apple","banana"] + ["cherry","melon"]
print(fruits)

['apple', 'banana', 'cherry', 'melon']

In the course of joining, essentially a new, third list is created. This is why this operation also works for immutable types.

Searching in a list

With the help of the in keyword it can be checked whether a list contains the given value. The result of the keyword is a boolean value, so it can be used, for example, in a conditional statement.

fruits = ["apple","banana","cherry","melon"]
if "banana" in fruits:
    print("There is a banana")
else:
    print("There is no banana")

There is a banana

Checking the contents of a list

By simply writing the list into the condition of a conditional statement, we can check whether there is any element in the list.

fruits = ["apple","banana","cherry","melon"]
if fruits:
    print("There is an element in the list")
else:
    print("The list is empty")

There is an element in the list

Mutable operations

The operations described in this part cannot be carried out for immutable types, because they result in a change to the value or to the set of the elements.

Modifying the elements of a list

The list is a modifiable sequence type, so the value of its individual elements can be changed. Similarly to querying, we can refer to the individual elements and assign values to them. 

fruits = ["apple","banana","cherry","melon"]
fruits[2] = "pear"
print(fruits)

['apple', 'banana', 'pear', 'melon']

Several elements can be given values at once, but in that case the new value also has to be of a sequence type.

fruits = ["apple","banana","cherry","melon"]
fruits[1:3] = ["pear", "orange"]
print(fruits)

['apple', 'pear', 'orange', 'melon']

Inserting a new element

Not only the value of the elements but also their set can be modified. The append() function inserts a new element at the end of the list.

fruits = ["apple","banana"]
fruits.append("cherry")
fruits.append("melon")
print(fruits)

['apple', 'banana', 'cherry', 'melon']

And with the help of the insert() function an element can be inserted at a given position.

fruits = ["apple","banana","cherry","melon"]
fruits.insert(1, "*BANANA*")
print(fruits)

['apple', '*BANANA*', 'banana', 'cherry', 'melon']

Deleting an element

The del keyword removes the element at the given index from the list.

fruits = ["apple","banana","cherry","melon"]
del fruits[1]
print(fruits)

['apple', 'cherry', 'melon']

The pop() method removes the given index – or the last element, if the index is not given.

fruits = ["apple","banana","cherry","melon"]
fruits.pop()
print(fruits)

['apple', 'banana', 'cherry']

The pop method differs from del not only in its syntax. The latter also deletes the removed value from memory, whereas when using pop the deleted element can still be stored.

fruits = ["apple","banana","cherry","melon"]
removed_item = fruits.pop(1)
print(f"The removed item is \"{removed_item}\"")

The removed item is "banana"

And with the help of the remove method elements can be deleted on the basis of their value. Only the very first occurrence of the value is deleted from the list.

fruits = ["apple","banana","cherry","melon"]
fruits.remove("cherry")
print(fruits)

['apple', 'banana', 'melon']

With the del keyword the whole list can also be deleted from memory:

fruits = ["apple","banana","cherry","melon"]
del fruits

Sorting lists

With the help of the sort() method we can arrange the values of our list into the natural order of the given variable type. This natural order is, for example in the case of text, alphabetical order.

cars = ['Ford', 'Mitsubishi', 'BMW', 'VW']
cars.sort()
print(cars)

['BMW', 'Ford', 'Mitsubishi', 'VW']

By applying the reverse boolean parameter the order can be reversed.

cars = ['Ford', 'Mitsubishi', 'BMW', 'VW']
cars.sort(reverse=True)
print(cars)

['VW', 'Mitsubishi', 'Ford', 'BMW']

In the case where our elements have no default order – for example if we have mixed elements of different data types in the list – a function can be given with the help of the key parameter which assigns to the current element a value that can be put in order, and then sort orders according to this value.

Functions, however, will be discussed later; this code fragment has been put here only for the sake of completeness!

In the example below we want to sort by the length of the text, instead of alphabetical order. For this, as a first step, we create a function called myFunc, which returns the length of the value received as a parameter. The sort() method of the list carries out the myFunc function on every element of the list and orders the elements on the basis of the value returned by the function.

# A function that returns the length of the value:
def  myFunc(e):
    return  len(e)

cars = ['Ford', 'Mitsubishi', 'BMW', 'VW']

cars.sort(reverse=True, key=myFunc)
print(cars)

['Mitsubishi', 'Ford', 'BMW', 'VW']
