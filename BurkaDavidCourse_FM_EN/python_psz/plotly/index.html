Plotly is a complex Python data visualisation module built on the Pandas module.

Installation:

pip install plotly

plotly.express is a simplified version of plotly in which most of the basic functions are available. We will deal only with this simplified version, but this is only a fraction of the possibilities of the full module. It is worth looking at the documentation for the possibilities.

Let us take the following figure example using plotly.express. This line creates a line chart, but when printed we only get the properties of the underlying object.

import plotly.express as px

fig = px.line(x=[1,2, 3], y=[1, 2, 3])
print(fig)

The figure has a tree layout in which the root has three properties: data, layout and frames. In the example above layout.legend is a nested dictionary, where legend is a key within the dictionary and its value is likewise a dictionary.

The chart is drawn in the following way:

import plotly.express as px

fig = px.line(x=[1,2, 3], y=[1, 2, 3])
fig.show()

Chart types

Loading the data

In this subsection we will use plotly_express's built-in Gapminder data for the charts. We make a filtered data table containing only the Hungarian data, and then another one in which we use only the most recent yearly data.

import plotly.express as px

gf = px.data.gapminder()

gf1 = gf.loc[gf['country'] == 'Hungary']

gf2 = (gf
       .sort_values(by=['country', 'year'])
       .groupby('country')
       .last()
       .reset_index())

Running this code fragment will be necessary in order to use several further code fragments. Either copy it to the beginning of the appropriate code, or from here on work in a second, independent cell in Jupyter.

In the code above we load one of plotly's test data sets into the gf variable. This is exactly as if we had read in data from a csv file. gf1 selects the Hungarian rows from the data set with a simple filter.

gf2 is a little more complicated and consists of several steps. If we chain many functions one after another, it is worth putting the whole call in brackets. In that case Python allows line breaks that it normally would not. In the example, for the sake of readability, we wrote every function call on a separate line, but logically this is one line.

First we sorted the data by country and year, then grouped it by country. After this we did not filter on a column, but called the last function on the whole data set, the result of which is that we get back the last year from every country group. Since we put the data in increasing order by year, this means that we got the most recent year's data for every country. Because of the grouping, the country ended up in the place of the index, so, in order to get the original data format, we still have to put the country back among the columns (reset_index).

The problem with the above solution is that it loses the original indices of the table and generates new ones. In our examples that follow this does not cause a problem, but it is easy to imagine a case in which the original indices are still needed after such filtering. The code fragment below ensures this:

import plotly.express as px

gf = px.data.gapminder()

gf1 = gf.loc[gf['country'] == 'Hungary']

gf2 = (gf
       .reset_index()
       .sort_values(by=['country', 'year'])
       .groupby('country')
       .last()
       .reset_index()
       .set_index('index'))
gf2.index.name = ""

With an extra reset_index call we ensure that the original indices get in among the columns and are not lost, and then, after the other operations, we restore the original indices using the set_index function. The extra line deletes the name “index” from the index. This does not really matter, but in this way the data structure will match the original 100%.

fig = px.line(gf1, x='year', y='gdpPercap')
fig.show()

Bar chart

Let us make a chart similar to the previous one, only as a bar chart.

fig = px.bar(gf2, x='country', y='gdpPercap')
fig.show()

Let us look at the interactive plotly features such as zooming. Let us draw the chart once more, after having sorted the values.

gf2.sort_values(by='gdpPercap', inplace=True)
fig = px.bar(gf2, x='country', y='gdpPercap')
fig.show()

Histogram

We can use a histogram to display distributions.

fig = px.histogram(gf2, x='lifeExp')
fig.show()

There is also the possibility of not taking each row as one occurrence, but weighting them. For example, if there is a count column.

import numpy as np

gf2['count'] = np.random.randint(1, 100, len(gf2))
fig = px.histogram(gf2, x='lifeExp', y='count')
fig.show()

Scatter and bubble chart

A scatter plot lets us see whether there is a correlation between different values. Here we will also use the hover_name parameter, by giving which we can see the name of the given country if we move the cursor onto the value. First let us make a scatter plot for the continent and life expectancy.

fig = px.scatter(gf2, x='continent', y='lifeExp', hover_name='country')
fig.show()

The reason why the correlation between the values is not clearly visible on the previous chart is that the continent is a categorical variable. For this very reason let us make another chart, only this time between life expectancy and GDP per capita.

fig = px.scatter(gf2, x='gdpPercap', y='lifeExp', hover_name='country')
fig.show()

The correlation between the two data series is logarithmic. Let us add a trend line and make the X axis logarithmic.

fig = px.scatter(gf2, 
                 x='gdpPercap', 
                 y='lifeExp', 
                 hover_name='country', 
                 trendline='lowess', 
                 log_x=True)
fig.show()

The bubble chart is a version of the scatter plot in which we display a third variable with the size of the bubbles.

fig = px.scatter(gf2, 
                 x='continent', 
                 y='lifeExp', 
                 hover_name='country',  
                 size='pop', 
                 size_max=55,
                 color='continent')
fig.show()

In the example there are a few very extreme values, so most countries will be of negligible size. We get a visually much more expressive result if we limit the size of the bubbles.

3D scatter plot

The 3-dimensional scatter plot is able to display 3 variables at once.

fig = px.scatter_3d(gf2, x = 'lifeExp',y = 'gdpPercap', z = 'pop', color = 'continent')
fig.show()

Pie chart

Let us display the population broken down by continent.

fig = px.pie(gf2, values='pop', names='continent')
fig.show()

Box plot

The advantage of the box plot is that it displays several statistical values of the given variable. Starting from the bottom it displays the minimum, the end of the first quartile, the median, the end of the third quartile and the maximum. The values marked with separate points count as outliers.

Let us display GDP per capita by continent in such a way that moving the cursor onto the values shows the countries.

fig = px.box(gf2, x='continent', y='gdpPercap', hover_name='country')
fig.show()

Animation

Plotly gives the possibility of using animations, which is particularly suitable for displaying the passing of time. Below, beyond the usual parameters, we also give the extreme values of the X and Y axes (range_x, range_y) so that the animation stays within the frame of the chart in every case, as well as the maximum point size (size_max) so that the large countries do not obscure the others.

px.scatter(gf, 
           x='gdpPercap', 
           y='lifeExp', 
           log_x=True,
           color='continent', 
           size='pop', 
           size_max=55, 
           hover_name='country',
           animation_frame='year', 
           animation_group='country',
           range_x=[100,100000], 
           range_y=[25,90])
